## The roast

> Saepuloh has entered 100+ bounties from a rice field on a Redmi A3 and won $0, but he still types 'gas terus' like rank 1 owes him money.

137 characters, one sentence — inside the competition's 1–140 gate, with the punch ("like rank 1 owes him money") saved for the last words.

## Why it's funny

The joke is saepuloh himself: a man standing in a rice field, phone in hand, firing off bounty pushes from a Redmi A3 — and after 100+ entries and $0 won, still hammering his catchphrase "gas terus" (keep pushing) as if rank 1 were a debt waiting to be collected. The setup is all true, specific detail no one else could claim; the twist is the last few words, which flip a losing streak into a delusion of credit. It needles him the way a friend would, with warmth underneath: the roast only lands because he genuinely never stops pushing.

## Run it

```bash
python3 main.py
```

This validates the line (one sentence ending with a period, 1–140 characters, no stray whitespace, double spaces, non-breaking spaces, or control characters) and writes it to `/output/entry.txt`.
